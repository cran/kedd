kedd: kernel estimation of a density and its derivatives

Arsalane Chouaib Guidoum, Amel Henider and Iago Giné-Vázquez

2026-11-20

1. Introduction

Given an i.i.d. sample \(X_1, \dots, X_n\) from a density \(f\), the kernel estimator of the \(r\)-th derivative \(f^{(r)}\) is \[ \hat f_h^{(r)}(x) \;=\; \frac{1}{n\,h^{r+1}} \sum_{i=1}^{n} K^{(r)}\!\left(\frac{x - X_i}{h}\right), \qquad r = 0, 1, 2, \dots \] where \(K\) is a kernel and \(h > 0\) the bandwidth. Its asymptotic mean integrated squared error is \[ \mathrm{AMISE}(h; r) \;=\; \frac{R\big(K^{(r)}\big)}{n\,h^{2r+1}} + \frac{\mu_2(K)^2}{4}\, h^4\, R\big(f^{(r+2)}\big), \qquad R(g) = \int g^2,\quad \mu_2(K) = \int x^2 K(x)\,dx, \] so the optimal bandwidth is of order \(n^{-1/(2r+5)}\): estimating a derivative requires a larger bandwidth than estimating the density itself. The whole difficulty is the choice of \(h\), which is what the package is about.

kedd provides

  • kernel.fun(), kernel.conv() — the kernels \(K^{(r)}\) and their convolutions \(K^{(r)} * K^{(r)}\), for ten named kernels and the power family Pow(s,t);
  • dkde() — the estimator \(\hat f_h^{(r)}\);
  • nine data-driven bandwidth selectors: h.amise(), h.ucv(), h.bcv(), h.ccv(), h.mcv(), h.tcv(), h.scv(), h.pcv(), h.mlcv().

All results are S4 objects with show() and ggplot2 plot() methods, and the \(O(n^2)\) criteria run in C++ (Rcpp) in parallel (OpenMP).

2. Kernels

2.1 The kernels

Ten named kernels and the power family Pow(s,t) (section 2.2) are available in every function through the argument kernel. “r max” is the highest order of the pointwise derivative \(K^{(r)}\) that is not identically zero.

kernel \(K(x)\) support r max
gaussian \(\phi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\) \(\mathbb{R}\) any
epanechnikov \(\frac34 (1-x^2)\) \([-1,1]\) 2
uniform \(\frac12\) \([-1,1]\) 0
triangular \(1-\lvert x\rvert\) \([-1,1]\) 1
biweight \(\frac{15}{16}(1-x^2)^2\) \([-1,1]\) 4
triweight \(\frac{35}{32}(1-x^2)^3\) \([-1,1]\) 6
tricube \(\frac{70}{81}(1-\lvert x\rvert^3)^3\) \([-1,1]\) 9
cosine \(\frac{\pi}{4}\cos\frac{\pi x}{2}\) \([-1,1]\) any
silverman \(\frac12 e^{-\lvert x\rvert/\sqrt2}\sin\!\big(\frac{\lvert x\rvert}{\sqrt2}+\frac{\pi}{4}\big)\) \(\mathbb{R}\) any
logistic \(\frac{e^{-x}}{(1+e^{-x})^2}\) \(\mathbb{R}\) 20
pow(s,t) \(c_{s,t}(1-\lvert x\rvert^s)^t\), \(c_{s,t} = \frac{s}{2B(1/s,\,t+1)}\) \([-1,1]\) \(\min(st,16)\)

For pow(s,t), \(\min(st, 16)\) applies when \(s\) and \(t\) are integers (16 otherwise).

The regularity \(q\) of a kernel is the largest \(m\) such that the pointwise derivative \(K^{(m)}\) is the derivative of \(K\) in the sense of distributions (\(K^{(m-1)}\) absolutely continuous). For \(m > q\), \(K^{(m)}\) misses the Dirac masses at the jumps of \(K^{(q)}\), and a criterion that evaluates it at the pairwise differences no longer estimates its target. Each criterion therefore restricts \(r\): \(r \le q\) for dkde and h.amise, \(2r \le q\) for UCV and TCV (\(K^{(2r)}\)), \(2r + 2 \le q\) for MCV, \(r + 2 \le q\) for BCV1 (convolution of \(K^{(r+2)}\)) and \(2r + 4 \le q\) for BCV2 and CCV. \(K^{(r)}\) (\(K^{(r+2)}\) for BCV1) must also be square integrable, and the selectors are capped at \(r = 8\) (logistic) and \(r = 6\) (Pow), the derivative orders implemented being 20 and 16. Above the limit the selectors return h = NA with a warning, and dkde() gives a warning; “—” means not available even at \(r = 0\):

kernel \(q\) dkde h.amise h.ucv, h.tcv h.mcv BCV1 BCV2, h.ccv
gaussian \(\infty\) any any any any any any
logistic \(\infty\) 20 8 8 8 8 8
silverman 3 3 (*) 1 (*) (*) (*)
triweight, tricube 3 3 3 1 0 1 —
biweight 2 2 2 1 0 0 —
epanechnikov, triangular, cosine 1 1 1 0 — — —
uniform 0 0 0 0 — — —

(*) The Silverman kernel is of order 4 (\(\mu_2(K) = 0\)): h.amise() returns the value of the Gaussian kernel with a warning, and BCV1, BCV2, MCV and CCV, built on the bias expansion of a second-order kernel, are not defined for it. For pow(s,t), \(q = \lceil t + 1 \rceil - 1\) (\(q = t\) for an integer \(t\)) from \(|x| = 1\), and \(q = \lceil s + 1 \rceil - 1\) from \(x = 0\) unless \(s\) is an even integer; \(q\) is the smaller of the two. For example pow(2,4): \(q = 4\) and 4, 4, 2, 1, 2, 0; pow(1.5,2.5): \(q = 2\) and 1, 1, 1, 0, —, —. h.scv (Gaussian kernel) has no limit and h.mlcv is for \(r = 0\) only; h.pcv has the limits of its criterion.

kernel.fun() evaluates \(K^{(r)}\) on a grid (or at given points) and returns an object of class kfun:

kf <- kernel.fun(kernel = "biweight", deriv.order = 1L)
kf
#> 
#> Kernel derivative of order 1
#> Kernel : biweight 
#> Range  : [ -1.1 , 1.1 ]
#> Points : 512
plot(kf)

kernel.conv() returns \(K^{(r)} * K^{(r)}\) (class kconv), the building block of the cross-validation criteria. At \(0\) it equals \((-1)^r R(K^{(r)})\):

kc <- kernel.conv(kernel = "logistic", deriv.order = 1L)
plot(kc)

2.2 The power family Pow(s,t)

For \(s > 0\) and \(t \ge 0\), \[ K_{s,t}(x) = c_{s,t}\,(1 - \lvert x\rvert^s)^t\, \mathbf 1_{\lvert x\rvert \le 1}, \qquad c_{s,t} = \frac{s}{2\,B(1/s,\, t+1)}, \] is passed as the string "pow(s,t)", or built with kernel.pow(s, t). It contains uniform (pow(s,0)), triangular (pow(1,1)), Epanechnikov (pow(2,1)), biweight (pow(2,2)), triweight (pow(2,3)) and tricube (pow(3,3)). Its constants are exact: \(\mu_k(K) = B\big(\tfrac{k+1}{s}, t+1\big) / B\big(\tfrac1s, t+1\big)\) and \(R(K) = s\,B(1/s, 2t+1) / \big(2\,B(1/s, t+1)^2\big)\).

kernel.pow(2, 3)
#> [1] "pow(2,3)"
all.equal(kernel.fun(kernel = "pow(2,2)")@y, kernel.fun(kernel = "biweight")@y)
#> [1] TRUE
Cpp_kernel_constants(kernel.pow(1.5, 2.5), 0L)
#>          c        mu2        mu4          R 
#> 1.23761742 0.10477184 0.02885017 0.85302293
plot(kernel.fun(kernel = kernel.pow(1.5, 2.5)))

Increasing \(t\) (or decreasing \(s\)) concentrates the kernel around \(0\):

3. Estimating a density and its derivatives

We use a bimodal sample whose true density is known, \(f = 0.6\,N(-1, 0.5^2) + 0.4\,N(1.5, 0.7^2)\):

set.seed(2027)
n <- 300
x <- c(rnorm(0.6 * n, -1, 0.5), rnorm(0.4 * n, 1.5, 0.7))
f_true <- function(t, r = 0L) {
  comp <- function(m, s) {
    z  <- (t - m) / s
    He <- switch(r + 1L, 1, z, z^2 - 1)        # Hermite polynomials
    (-1)^r * He * dnorm(z) / s^(r + 1)
  }
  0.6 * comp(-1, 0.5) + 0.4 * comp(1.5, 0.7)
}

dkde() computes \(\hat f_h^{(r)}\) (class dkde). When h is missing, the UCV bandwidth is used.

f0 <- dkde(data = x)
f0
#> 
#> Kernel density estimate
#> Kernel     : gaussian 
#> Bandwidth h: 0.234919 
#> n          : 300 
#> Grid points: 512
p <- quiet(plot(f0))
p + ggplot2::stat_function(fun = f_true, linetype = "dashed")

The first derivative, estimated with its own (SCV) bandwidth (dashed: true \(f'\)):

h1 <- h.scv(x, deriv.order = 1L)
p1 <- quiet(plot(dkde(data = x, h = h1@h, deriv.order = 1L)))
p1 + ggplot2::stat_function(fun = f_true, args = list(r = 1L), linetype = "dashed")

Compare with the density bandwidth, which is too small for \(f'\):

c(h_density = f0@h, h_derivative = h1@h)
#>    h_density h_derivative 
#>    0.2349190    0.3684841
plot(dkde(data = x, h = f0@h, deriv.order = 1L), band = FALSE)

Every kernel can be used, each with its own bandwidth. Here the Gaussian, logistic and power pow(2,4) kernels with UCV bandwidths, against the true density (dashed):

grid <- seq(-3, 4, length.out = 300)
est <- do.call(rbind, lapply(c("gaussian", "logistic", "pow(2,4)"), function(k) {
  d <- dkde(x = grid, data = x, h = h.ucv(x, kernel = k)@h, kernel = k)
  data.frame(x = d@x, y = d@y, kernel = k)
}))
ggplot2::ggplot(est, ggplot2::aes(x, y, colour = kernel)) +
  ggplot2::geom_line(linewidth = 0.8) +
  ggplot2::stat_function(fun = f_true, colour = "black", linetype = "dashed") +
  ggplot2::theme_minimal()

4. Bandwidth selectors

All selectors return an object of class bandwidth (slots h, min.obj, hos, method, …, and for PCV criterion and groups). Writing \(\psi_h(u) = u/h\) for the scaled differences \(X_j - X_i\), the criteria minimised are:

  • AMISE (h.amise) — closed-form rule with a normal reference \(\hat h = \hat\sigma\,\Big[\frac{243(2r+1)R(K^{(r)})}{35\,\mu_2(K)^2\,n}\Big]^{1/(2r+5)}\) (the over-smoothing bandwidth \(h_{os}\) used to bound all searches).
  • UCV (h.ucv) — unbiased / least-squares cross-validation, \(\mathrm{UCV}(h) = \frac{R(K^{(r)})}{nh^{2r+1}} + \frac{(-1)^r}{n(n-1)h^{2r+1}} \sum_{i\ne j}\big(K^{(r)}*K^{(r)} - 2K^{(2r)}\big)\Big(\frac{X_j-X_i}{h}\Big)\).
  • BCV (h.bcv) — biased cross-validation, which estimates \(R(f^{(r+2)})\) in the AMISE either with \(K^{(r+2)}*K^{(r+2)}\) (BCV1) or with \(K^{(2r+4)}\) (BCV2).
  • CCV (h.ccv) — complete cross-validation (higher-order bias correction).
  • MCV (h.mcv) — modified cross-validation.
  • TCV (h.tcv) — trimmed cross-validation (pairs closer than \(1/(nh^{2r+1})\) are discarded in the \(K^{(2r)}\) term).
  • SCV (h.scv) — smoothed cross-validation (Gaussian kernel): the squared bias is estimated from a Gaussian pilot \(\tilde f_g\), which gives a closed form in terms of \(\phi^{(2r)}\) for any \(r\).
  • PCV (h.pcv) — partitioned cross-validation (Marron, 1987): the sample is partitioned at random into m subsamples, a score (criterion = "UCV" by default, or TCV, MCV, CCV, BCV1, BCV2) is computed in each subsample at the bandwidth \(h\,m^{1/(2r+5)}\) suited to its size, and \(h\) minimises the average; the across-sample variability is reduced and the cost divided by about m; with nrep > 1 the score is also averaged over nrep random partitions.
  • MLCV (h.mlcv) — maximum-likelihood (leave-one-out) cross-validation, density only.
bw <- h.ucv(x)
bw
#> 
#> Call: UCV bandwidth selector
#> Kernel      : gaussian 
#> Deriv. order: 0 
#> Bandwidth  h: 0.234919 
#> Objective   : -0.277091 
#> h_os        : 0.495297
plot(bw)

lines() returns a ggplot2 layer, so several criteria can be drawn together:

p$plot +
  lines(h.bcv(x), color = "darkred") +
  lines(h.ccv(x), color = "darkorange") +

4.1 Comparison on the bimodal sample

The integrated squared error \(\mathrm{ISE}(h) = \int (\hat f_h^{(r)} - f^{(r)})^2\) measures the quality of each selected bandwidth:

ise <- function(h, r) {
  d <- dkde(x = seq(-4, 5, length.out = 400), data = x, h = h, deriv.order = r)
  sum((d@y - f_true(d@x, r))^2) * diff(d@x[1:2])
}
sel <- list(AMISE = h.amise, UCV = h.ucv, BCV1 = h.bcv,

Two well-known behaviours show up in such comparisons:

  • UCV is unbiased but highly variable, and tends to undersmooth, all the more as \(r\) grows (Härdle, Marron and Wand, 1990); its selected bandwidth may even decrease with \(r\) on a given sample.
  • BCV, CCV and MCV are much more stable but biased towards large bandwidths. On multimodal samples, especially for \(r \ge 1\), their criterion can be decreasing on the whole search interval \([0.01\,h_{os},\, 2\,h_{os}]\): the selector then returns the upper bound and warns that “minimum occurred at one end of the range”. Plotting the criterion (plot()) is the simplest diagnostic; the interval can be changed with lower and upper.

6. Parallel computation

The \(O(n^2)\) criteria (sums over all pairs \(X_i, X_j\)) are computed in C++ and split between the processor cores with OpenMP. The argument nthreads of every selector and of dkde() sets the number of threads of that call:

  • nthreads = 0 (default): all processors;
  • nthreads = k > 0: k threads (1 = sequential);
  • both are capped by the environment variable OMP_THREAD_LIMIT, and a call never changes the threads used by later calls.

Cpp_omp_threads() reports how many threads a call actually gets. The results do not depend on nthreads, only the computing time does:

c(all = Cpp_omp_threads(0L), two = Cpp_omp_threads(2L))
#> all two 
#>   2   2
y <- rnorm(1500)
system.time(h_seq <- h.ucv(y, nthreads = 1L)@h)
#> utilisateur     système      écoulé 
#>        1.06        0.00        1.08
system.time(h_par <- h.ucv(y, nthreads = 0L)@h)
#> utilisateur     système      écoulé 
#>        1.21        0.00        0.84
all.equal(h_seq, h_par)
#> [1] TRUE
